# Opportunity Qualification Rubric

## Lead Scoring Framework

| Criterion | Weight | Score (1-5) | Evidence Required |
|-----------|--------|-------------|-------------------|
| Business verification | 20% | | CIPC / website / directory |
| Contact verification | 20% | | Phone / email / LinkedIn |
| Decision-maker access | 20% | | Role title / confirmation |
| Volume/capacity fit | 15% | | Stated or estimated demand |
| Interest signal | 15% | | Inquiry, event attendance, content |
| Timing alignment | 10% | | Budget cycle / procurement window |

## Fit Score Interpretation

- **5 (Excellent)**: All criteria met, verified contact, clear next step
- **4 (Strong)**: Most criteria met, minor verification gaps
- **3 (Moderate)**: Mixed evidence, requires follow-up
- **2 (Weak)**: Limited evidence, speculative fit
- **1 (Poor)**: Unverified or mismatched

## Next Action Templates

| Score | Action |
|-------|--------|
| 5 | Immediate outreach — draft email for human review |
| 4 | Outreach prep — verify remaining gaps first |
| 3 | Deep-dive — gather more evidence |
| 2 | Monitor — add to watch list |
| 1 | Discard — document reason |
