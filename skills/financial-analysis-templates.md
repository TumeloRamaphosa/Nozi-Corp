# Financial Analysis Templates

> Workflow/templates adapted from agency-agents `finance/finance-financial-analyst.md`.

## Needs Analysis Memo (FSP Demo)

```markdown
# Needs Analysis: [Demo Client ID]

## Assumptions (explicit)
| Assumption | Base | Upside | Downside | Source |

## Situation Summary
## Stated Objectives (from intake)

## Strategic Options (practitioner review — NOT client advice)
| Option | Fit | Risks | Info needed |

## Scenario Notes
- Base / upside / downside drivers

## Open Questions → decisions.json
```

## Rules

- No specific product/fund/policy picks.
- Label facts vs illustrative projections.
- Sensitivity: note if conclusion flips on key assumption change.
