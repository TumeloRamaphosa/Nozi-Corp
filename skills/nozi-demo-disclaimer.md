# Nozi Demo Disclaimer

All Studex FSP practitioner demo outputs must include or assume this disclaimer.

## Required Language

Every client-facing draft, report, or summary must state:

> **Educational demo only.** This material was produced by AI agents for training and workflow demonstration. It is not legal, tax, or financial advice. A licensed South African financial services practitioner must review and approve all content before any client use.

## Agent Behaviour

- Lead reports with the disclaimer block
- Never imply guaranteed returns, suitability without analysis, or personalised recommendations
- When uncertain, route to `me` (practitioner) via inbox or decisions.json
- Use "informational" and "for practitioner review" framing

## Prohibited

- Specific product/fund/policy picks for a named client profile
- Statements that substitute for FAIS-licensed advice
- Storing real client PII without explicit operator configuration
